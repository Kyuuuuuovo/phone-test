# 宠物机(电子宠物机)设计 spec

> 状态:**设计阶段**,未接入 app。外观稿见 [pet-machine-demo.html](pet-machine-demo.html)。
> 本文记录 user 已拍板的决策 + 待定项,接入时照此实现。

## 定位

手机里养一只**电子宠物机**(角落生物宠物机风)。三条主线:
1. **养成** —— 喂食/玩耍/洗澡/睡觉,4 项状态随真实时间衰减。
2. **赚养** —— 玩内置小游戏赢**金币**,金币买食物/玩具/家具/衣服/稀有蛋。
3. **陪伴** —— 宠物状态**注入 AI 聊天上下文**,所有角色都知道你在养它(铁律 3:只陈述事实)。

机身**跟随主题配色**(13 套主题各一台);宠物本体是手绘像素,用自己的随机配色。

---

## 已定决策(user 拍板)

1. **形象 = 程序化生成,不用 AI 出图。**
   手绘像素**底模**(猫/狗/鸟/蛇/兔/熊/企鹅…)× 随机**配色**(精选色库)× **花纹**(纯色/白肚皮/圆点/条纹)× **腮红** × **配饰**。随机的只是换色/花纹/配饰,底模是手画的 → **怎么摇都好看,不会崩**。蛋孵化 = 随机得到一只。

2. **健康机制:会生病 / 离家出走,但有「不死模式」开关。**
   - **生病**:状态长期偏低 → 生病态(蔫蔫的),只影响心情 + 注入文本,照顾后恢复。**两种模式都有**。
   - **离家出走**:**仅非不死模式** + 长期完全不管(留宽限期)才触发,宠物离开。
   - **不死模式**(settings 开关):关掉离家出走,只会一直生病不会真失去。默认值**待定**。

3. **金币用途**(来源 = 小游戏):
   - 食物(加饱食)· 玩具(加心情)—— demo 已做
   - **房间家具 / 装饰**(可摆放,布置自己的房间场景)
   - **稀有蛋 / 解锁新物种**
   - **宠物衣服 / 配饰**(帽子/围巾/小翅膀等,叠在底模上换装)
   - ❌ 不做「买游戏关卡」

4. **一起养粒度:一只宠物,全局,所有角色聊天都能看到它的状态。**
   宠物是「用户的宠物」,注入到所有(非架空)会话。可选一个「主要照顾者」角色名,用于「你和 XX 一起养」措辞。

## 外观(见 demo)

- **机身**:圆角方壳 + 顶部椭圆挂绳孔 + 两只圆耳朵 + 塑料高光/暗部,LCD 点阵屏。
- **取色全派生自主题变量**:外壳 = `--accent` 三档渐变(高光/主色/暗部)+ 描边;屏幕 = `--surface` 染 10% accent;按钮 = `--surface`/`--border`。深色主题也成立。
- **三枚物理键**:◀ 选择 / ● 确定·互动 / 选择 ▶。屏底排 4 个动作图标,A/C 移光标、B 确定(真·宠物机交互)。
- **场景**:房间(墙/地/窗/地毯/盆栽,**可买家具装饰**)、户外(天/地/太阳/树,**做小游戏**)。

## 像素生成器(demo 已实现)

- `SPECIES[key].grid` —— 16×16 字符底模,符号 `o`描边 `b`身体 `s`暗部 `e`眼 `p`腮红 `l`亮部 `a`特征(喙/内耳/尾)。
- `PALETTES` —— 精选色库,每套含 `{o,b,s,l,a,p,e}`,任意组合都协调。
- `PATTERNS` —— `plain/belly/spots/stripes`,overlay 只改 `b` 格,不动眼睛描边。
- 腮红开关 —— 关掉把 `p` 还原成 `b`。
- **配饰层(待加)** —— 衣服/帽子等再叠一层 overlay grid。
- 表情 —— 嘴用 SVG overlay 跟心情实时变(笑/平/撇嘴);生病态可加"汗滴/螺旋眼"。

## 状态系统

- **4 状态**:饱食 / 心情 / 精力 / 清洁(0-100)。
- **阶段**:蛋 → 幼年 → 少年 → 成年(按天数)。
- **健康**:健康 / 生病 / (离家)。
- **衰减**:按真实时间,boot 时按 `lastTickAt` 结算(同 schedule/cycle-notify 套路),不需后台。

## 金币 / 商店 / 小游戏

- 金币来源 = 小游戏。商店分类:食物 / 玩具 / 家具 / 衣服 / 稀有蛋。
- 小游戏:demo 有「接食物」。候选更多款(记忆翻牌 / 节奏点击 / 喂食时机…)—— **具体几款待定**。

## 注入 AI(铁律 3)

- `buildSystemPromptParts` 加一段 `# 当前宠物`,与 `# 当前行程` 同模式:`parts.push({key:'pet', title:'# 当前宠物', body, kind:'data', editRoute:'pet-machine'})`。
- **全局注入所有非架空会话**,受全局 toggle `settings.petInjectToChat` 门控。
- 纯事实陈述,**不写**「你该多陪它」。示例:
  ```
  # 当前宠物
  你和樱一起养着一只叫「糯米」的奶油色企鹅(电子宠物机),养到第 12 天,现在是成年。
  此刻它心情很好,有点饿了、精力充沛、该洗澡了。
  刚才樱喂过它。
  ```

## 数据模型草案(接入时 bump DB_VERSION)

| store | 说明 |
|---|---|
| `pet`(单例) | species / palKey / pattern / blush / accessories[] / name / bornAt / lastTickAt / health(`healthy`/`sick`/`away`)/ mainCarerCharacterId? |
| `pet`(并入状态) | hunger / mood / energy / clean / lastActionKey / lastActionAt |
| `petRoom` | 已购家具 + 摆放布局(furnitureId + x/y) |
| `petInventory` | 已购食物/玩具/衣服/家具(或直接扣币即时生效,清单 TBD) |
| `settings` | `petMachineEnabled` / `petInjectToChat`(全局门控)/ `deathlessMode` / `petCoins` |

- 路由 `pet-machine`,home 第二页加入口图标。
- 蛋是特殊形态(单例 pet 的 `stage='egg'`);稀有蛋买来 = 换一颗待孵的蛋。
