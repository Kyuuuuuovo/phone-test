## 一、小游戏背景(各 **640×640 不透明 PNG**)

跟房间背景同规格(填满、像素风)。玩小游戏时这张图**临时替换房间背景**。构图要求:**上 2/3 大片留空**(道具从上方掉落 / 飞过),**下 1/3 是地面 / 台面**(宠物站在这玩),正中不要堆东西挡住宠物。

1. **接食物 · 厨房**(`game_kitchen.png`):暖奶油色厨房。下 1/3 木纹料理台;墙上挂小锅铲、木置物架;右上角小窗透柔光。上方大片空。
2. **接食物 · 野餐**(`game_picnic.png`):户外草地 + 樱粉/薄荷格子野餐布(下 1/3)。上方蓝天白云,远处一两丛小树。空中留给水果点心掉落。
3. **钓鱼 · 池塘**(`game_pond.png`):木栈桥 + 池塘水面占下半,睡莲、芦苇点缀;上半是岸边绿地 + 浅天。宠物坐桥边钓,鱼从水里咬钩。
4. **接星星 · 夜晚**(`game_starfall.png`):深紫蓝夜空 + 散落星点 + 一弯月;下 1/4 是草坡剪影。星星 / 流星从上方落。(夜间主题专用)

> 先做 **1(厨房)+ 2(野餐)** 看效果。

## 五、宠物装饰(戴在宠物身上,会跟宠物一起浮动)

**机制已跑通**:装饰是叠在宠物身上的一层,跟宠物放在同一个「会上下浮动的容器」里 → 自动跟着一起浮,不用逐帧对齐。配合这个机制,**最省事的画法**:

- 每件装饰画在 **320×320 透明 PNG**(跟宠物同尺寸),**直接画在它戴在标准猫身上时该出现的位置**(帽子在头顶、围巾在脖子、眼镜在眼睛上)。app 按 1:1 盖上去就行,不用再算坐标。
- **用 `pets/pet_cat.png` 当对齐参照**(照这只猫的头 / 脖 / 眼位置画)。
- 落地 `pet-machine-assets/accessories/`。

清单:`acc_bow.png` 蝴蝶结(头顶)· `acc_hat.png` 小帽子(贝雷帽 / 尖帽)· `acc_scarf.png` 围巾(脖子)· `acc_glasses.png` 眼镜;扩展可选 `acc_crown.png` 小皇冠 · `acc_flower.png` 头花 · `acc_headphone.png` 小耳机。

> **将来多宠物时注意**:这套是「贴着这只猫画」的;以后加狗 / 兔等,要么每只重画一套对齐版,要么改成「160² 单件 + app 按每只宠物的锚点定位」。现在一只猫,320² 对齐版最省事。
