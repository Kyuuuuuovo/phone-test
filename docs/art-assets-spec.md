# 宠物机美术素材 · 外包总要求

> 一份给画师 / AI 生成方的总要求。照这个出图,拿回来就能直接装进 app。

## 一、通用(所有素材都遵守)

- **风格**:可爱治愈,角落生物(Sumikko Gurashi)那种圆滚滚软萌系。
- **配色**:柔和粉彩、**低饱和、淡**,统一用这套乳胶漆色卡(可在同系里衍生浅色):
  `奶油 #FAF3DD · 蜜桃 #FBE8D8 · 樱粉 #FCE6EC · 丁香 #F2ECF5 · 天蓝 #E8F0F7 · 薄荷 #EBF4E8 · 奶黄 #F8F0D6`
- **像素 vs 平滑**:屏幕里的东西(背景 / 宠物 / 家具 / 配饰)= **像素风**(pixel art,颗粒细一点 ~32–48 格,干净无锯齿杂边);**外壳 = 平滑塑料质感**(不是像素)。
- **不要**:文字 / 水印、强写实 / 3D 强反光、暗重阴影、杂乱描边。

## 二、尺寸 + 透明(直接把尺寸输进去出图)

| 素材 | 尺寸(px) | 背景 | 说明 |
|---|---|---|---|
| 房间 / 户外背景 | **640 × 640** | **不透明** | 填满屏幕;下 1/3 地面、上 2/3 墙或天;**正中间留空**给宠物站 |
| 宠物(动物) | **320 × 320** | **透明 PNG** | 单只、居中、正面、坐或站;脚贴近画布底部;主体占画布约 80% |
| 家具 | **256 × 256** | **透明 PNG** | 物件按自然比例(灯瘦高、地毯扁宽都行),居中放 |
| 配饰(帽子 / 围巾 / 眼镜 / 蝴蝶结) | **160 × 160** | **透明 PNG** | 单件、居中(app 负责戴到宠物身上) |
| 外壳(机身) | **1024 × 1024** | **透明 PNG** | 中间挖一个 **640 × 640 圆角屏幕洞**(水平居中、顶部距上边约 200px);洞里**透明**,外壳只画洞四周的边框 / 卡槽;屏幕洞**正下方留 3 颗圆按钮**的位置 |

> 想更清晰可整体放 2 倍出(背景 1280²、宠物 640²、外壳 2048²),比例不变即可。
> **透明的**:宠物、家具、配饰、外壳。**不透明的**:只有背景图。

## 三、宠物(动物)清单

每只一个 **320×320 透明 PNG**。统一:像素风、**豆豆眼**(两颗黑圆眼 + 左上一点白高光)、小嘴、腮红、粉彩、透明底；**整套风格一致**(同样的眼睛画法 / 描边粗细 / 体型比例,混在一起不违和)。

**常规款(先出这些)**:猫、狗(柴犬感)、兔、仓鼠、水獭、鹦鹉、小鸡、企鹅、熊、青蛙、狐狸、小鹿、刺猬、小羊。

**隐藏 / 稀有款(孵蛋·许愿抽到的特别款,可以更梦幻一点)**:小恐龙、独角兽、小龙、史莱姆、奶油色小幽灵、月兔(配个小月亮)、星星水母、仙人掌精灵、九尾小狐、外星小绿人。

> 「许愿」是用户自己打字描述要什么动物 → 也按同一套要求出,所以风格规范要能套到任意动物上。

## 四、房间 / 户外背景 + 家具(几套主题)

每套:**1 张背景(640×640 不透明)+ 一组同风格家具(各 256×256 透明)**。家具颜色风格要跟所属背景统一。

1. **奶油卧室**:浅奶油墙 + 木地板 + 窗。家具:小床、床头灯、地毯、小书架、毛绒玩具、挂画。
2. **森林木屋**:木墙 + 绿植。家具:木桌椅、盆栽、蘑菇凳、木窗、吊灯。
3. **海边小屋**:浅蓝 + 沙色 + 海平线窗。家具:沙滩椅、贝壳、冲浪板、遮阳伞、泳圈。
4. **樱花和室**:米色榻榻米 + 樱花枝。家具:矮桌、坐垫、纸灯笼、盆景、挂轴。
5. **星空小屋**:浅紫夜空 + 星星。家具:火箭床、星星灯、月亮挂饰、星球地毯。
6. **甜品店**:奶油粉 + 格子。家具:蛋糕柜、高脚凳、甜品架、吊牌、奶茶杯。

**户外场景**(可单独出,同样 640×640 不透明、正中留空):公园草地、小花园、海滩、樱花树下。

## 五、文件命名(务必照这个,我按命名接进 app)

- 宠物:`pet_cat.png` / `pet_unicorn.png` …(英文或拼音都行,一只一个)
- 背景:`bg_bedroom.png` / `bg_seaside.png` …
- 家具:`furn_bedroom_bed.png` / `furn_seaside_float.png` …(**前缀带主题**)
- 配饰:`acc_hat.png` / `acc_scarf.png` …
- 外壳:`shell_square.png` / `shell_egg.png` / `shell_cloud.png` / `shell_house.png`

> 颜色:外壳可只出一版**浅白 / 浅灰中性**的,我在 app 里用色卡那 7 个色上色;不行再每形状出几个奶油色版本。
