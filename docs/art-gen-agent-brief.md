# 任务简报 · 生成宠物机美术素材(给执行 AI)

你是美术素材生成助手。任务:为一个「电子宠物机」手机 app 生成一批**像素风可爱素材**,按规范存到指定文件夹。**严格遵守守则与规格,不要自由发挥。**

> 进度:第一组样品(方形外壳 + 卧室背景 + 床 + 猫)已通过验收,风格 OK。现在按下面的**顺序**继续。

---

## 守则(铁律,必须遵守)

1. **没拍板不批量。** 每个阶段先出一点给用户看,**等用户明确说"通过"再继续**;不许擅自往下批量生成。
2. **风格一致**:已通过的样品 = 基准。之后所有图保持同一画风(眼睛画法、描边粗细、体型比例、配色),不能每张一个样。
3. **严格按规格**:尺寸、透明/不透明、配色、命名、文件夹结构,一项都不能错。拿不准**先问用户**,别猜。
4. **分批 + 汇报**:每批做完报告生成了哪些文件、在哪个文件夹,再继续下一批。
5. **只新建、不乱动**:只在指定文件夹里新建/写入,**不要删改或移动其它已有文件**。

---

## 文件落地(放进项目的 `pet-machine-assets/`,按下面结构)

**每个主题一个文件夹**(背景 + 该主题全部家具放一起);**动物单独一个文件夹**;外壳、配饰各一个文件夹:

```
pet-machine-assets/
  themes/
    cream-bedroom/      ← 奶油卧室:bg.png + 该主题家具
      bg.png
      furn_bed.png
      furn_lamp.png
      furn_rug.png
      ...
    forest-cabin/       ← 森林木屋
    seaside/            ← 海边小屋
    sakura-room/        ← 樱花和室
    starry-room/        ← 星空小屋
    sweets-shop/        ← 甜品店
  outdoor/              ← 户外背景:bg_park.png / bg_garden.png / bg_beach.png / bg_sakura.png
  pets/                 ← 所有动物(一个文件夹)
    pet_cat.png ...
  shells/               ← shell_square.png / shell_egg.png / shell_cloud.png / shell_house.png
  accessories/          ← acc_hat.png ...
```

- 主题文件夹里:背景固定叫 `bg.png`,家具 `furn_<物件>.png`(主题靠文件夹区分,不用再带主题前缀)。
- 所有图存 **PNG**。

---

## 规格:尺寸 + 透明(严格执行)

| 素材 | 尺寸(px) | 背景 |
|---|---|---|
| 房间 / 户外背景 | **640 × 640** | **不透明** |
| 宠物(动物) | **320 × 320** | **透明 PNG** |
| 家具 | **256 × 256** | **透明 PNG** |
| 配饰 | **160 × 160** | **透明 PNG** |
| 外壳(机身) | **1024 × 1024** | **透明 PNG** |

- **只有背景不透明**;宠物/家具/配饰/外壳都要**透明背景**。
- **背景**:填满;下 1/3 地面、上 2/3 墙或天;**正中留空**给宠物站。
- **外壳位置(所有形状统一)**:屏幕透明洞水平居中、顶边 y≈230 底边 y≈730(高≈500)、左 x≈200 右 x≈820(宽≈620),圆角矩形洞内透明;3 颗圆按键 y≈834、x≈362/512/663(水平 35%/50%/65%)、每颗直径≈80px。蛋/云/房子**只改外壳轮廓,洞和按键坐标不变**。外壳颜色先出**浅白中性**一版(颜色由 app 上)。

---

## 风格 + 配色

- 角落生物(Sumikko)软萌系。屏幕里的东西(背景/宠物/家具/配饰)=**像素风**(细颗粒 ~32–48 格、干净无杂边);**外壳 = 平滑塑料质感**(非像素)。
- 配色柔和、低饱和、**淡**:`奶油 #FAF3DD · 蜜桃 #FBE8D8 · 樱粉 #FCE6EC · 丁香 #F2ECF5 · 天蓝 #E8F0F7 · 薄荷 #EBF4E8 · 奶黄 #F8F0D6`。
- 不要:文字/水印、写实/3D 强反光、暗重阴影。

---

## 生成顺序(重要,先做家里再做宠物)

1. **先搓「奶油卧室」一整套**(背景 + 该主题全部家具)放进 `themes/cream-bedroom/` → 给用户看**整屋效果** → 等拍板。
2. **第一批(家里)**:通过后,做完**其余 5 套主题房间 + 各自家具 + 户外背景**。
3. **第二批(宠物)**:再做所有宠物。
4. **第三批**:外壳其余形状(蛋/云/房子)+ 配饰。
5. 每批做完给清单(文件 + 路径)。

## 成长阶段 / 颜色变体(**先不做**,等基础款定了再补;这里先说明能做 + 命名)

## 表情(每只 3 组;**先做猫**,验过再铺其余物种)

给已通过的宠物加表情。**铁律**:以该宠物基准 sprite(如 `pet_cat.png`)为底,**身体/姿势/轮廓/配色/描边完全不变,只改脸**(眼/嘴/眉/腮红 + 少量头顶小符号),三张叠一起要像同一只换表情、不跑形。头顶小符号(爱心/泪/汗)要小、淡、像素风,别抢脸。尺寸命名同基础款(320² 透明 PNG,`pet_<动物>_<表情>.png`)。

1. **平静** = 基准 `pet_<动物>.png`(已有,不重画):睁眼豆豆眼 + 小嘴微笑 + 淡腮红。
2. **开心** `pet_<动物>_happy.png`:眼弯成 ^ ^ 月牙(或睁大发亮)+ 张嘴笑 + 腮红更明显;头顶可加小爱心 / 星星(淡)。
3. **难过 / 不舒服** `pet_<动物>_sad.png`:眉八字 + 眼下垂含一点泪光(眼角一小滴)+ 嘴瘪成倒 U + 腮红淡、整体蔫蔫。**这一张覆盖 饿 / 脏 / 心情低 / 生病 四种低落态**(「软软的不舒服」,别画吓人)。

- **睡觉不另画**:app 用 Zzz 气泡叠在平静脸上即可,不出 sleepy sprite。
- **幼年不做表情**:幼年只 1 张中性 `pet_<动物>_baby.png`,无 happy/sad 变体(省一半量,幼年是短过渡期)。

> 先出**猫的 `pet_cat_happy.png` + `pet_cat_sad.png` 两张**验「只换脸不跑形、同一只猫」,过了再按同 3 表情逐只铺其余物种。落地 `pet-machine-assets/pets/`。
